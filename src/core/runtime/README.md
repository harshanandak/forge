# Runtime API

`captureBlock(root)` reads a bounded, root-contained set of regular files, validates the manifest and schemas, and retains immutable text plus an exact byte digest. `Catalog(config, captures)` resolves nouns, renames and typed slots without activating code. `list()` and `describe()` are reads. `addBlock(root, trust)` captures and reports whether the same bytes already have admission; it does not write config or storage.

`Runtime(catalog, trust, options).invokeText(bytes)` is the outside JSON boundary. `invoke(value)` is for trusted embeddings with parsed JSON values. Both use the same resolve, context bind, trust check and sync invocation path. The returned value is always a result envelope. A refused admission opens no services. A refused output is never returned as a success.

The `trusted-action-sync/v1` entry is self-contained CommonJS exporting operation-name functions through `module.exports`. Each function receives frozen JSON input and config plus explicitly bound service clients. There is no package loader, ambient executable access or outside lifecycle hook. The VM supplies a sync JavaScript deadline, including output inspection; it is not a security sandbox or a preemption guarantee for native host clients. Host clients own their own native I/O limits and must enforce effects and lease fencing at the write boundary. A runtime timeout does not roll back an effect that already happened, so execution failures require reconciliation before repetition.

The embedding's service factory receives the selected instance and its bound context. Use `catalog.bindings(instance)` to build only the declared clients. A nonempty binding set without a factory is refused. The factory owns partial-open rollback (the contract's `openAll` helper provides it). Return the contract's owned or borrowed handle; owned handles close on success, refusal and deadline, and borrowed handles are left to their owner. Cleanup failure is INCOMPLETE.

`TrustStore` is a human-controlled authority object; never inject it into block services. The transport authenticates the caller identity instead of taking a human claim from untrusted input. Admission and effect grants bind to exact captured bytes. Persistence is injected through `TrustRecords` and must use the state owner; the default map is ephemeral and creates no files. `secretReference` accepts only a validated named reference and never resolves plaintext.

`assembleCoreManifest(base, fragments)` merges the area-owned operation fragments and refuses duplicates. Assembly supplies executable core handlers. Package assembly must expose the catalog/runtime/trust APIs and copy their JSON assets; those shared build/export changes are owned separately. The installed artifact proof uses the built runtime API directly until the generated transports are connected.
