# Forge 0.1.0 Stable Release

This work folder turns the open-ended beta backlog into a bounded stable-release program.

Authority: Forge Kernel epic `068374e5-c0af-493f-b50b-972364e5d6c7`.

## Goal

Ship `forge-workflow@0.1.0` only after the advertised user journey is reliable on supported platforms and harnesses. Stable does not mean completing every roadmap issue. It means the supported contract is truthful, usable without maintainer intervention, and protected by repeatable release evidence.

## Artifacts

- `plan.md` — release boundary, blocker cohort, parallel tracks, gates, schedule, and rollback.
- `tasks.md` — executable merge-train sequence.
- `decisions.md` — locked scope and operating decisions.
