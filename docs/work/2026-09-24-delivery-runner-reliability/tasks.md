# Approved bounded work

1. Reconcile the two Claude source findings against saved runtime evidence.
   Select one minimal distinguishing reproduction and record the chosen scope
   in the issue before editing production code.
2. Assign one owner for the selected shared fix. Demonstrate the focused bad
   case, apply the minimum correction, and verify it with existing deadlines,
   coverage, failure handling, and cleanup preserved. Measure the same workload.
3. Obtain independent spec then quality review, update the scoped documentation,
   and commit through normal hooks. Only then run canonical validation and use
   an unchanged passing receipt for the personal-account push.

Do not treat a focused pass as complete validation or close the issue before
live delivery verification. Unrelated findings remain separately tracked.
