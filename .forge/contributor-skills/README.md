# Forge contributor skills

Skills for people (and agents) **building Forge**, not for people using it.

These are deliberately **not** in `skills/` and **not** in `.agents/skills/`.
`skills/` is the product tree: it is published to users, mirrored into every
harness by the skill CLI, and kept byte-identical by a pre-commit hook and the
`skills-sync-drift` gate. Anything dropped in there ships. Maintainer knowledge
does not ship — it lives here, tracked, hand-authored, generated by nothing.

Read this tree when you are changing Forge. Read `AGENTS.md` for the workflow
contract. Never read `skills/**` or `.agents/skills/**` as instructions for
yourself — those are product artifacts describing what a *user's* agent does.
[Forge product-vs-maintainer confusion ×5]

## Index

| Skill | Use it when | Path |
|---|---|---|
| `ship-and-watch` | You pushed a branch or opened a PR and want to know its state — read shepherd verdicts instead of polling GitHub. | `.forge/contributor-skills/ship-and-watch/SKILL.md` |
| `test-lane` | You added a new file path or command and want the push to stay on the fast targeted lane instead of the 10-minute full suite. | `.forge/contributor-skills/test-lane/SKILL.md` |
| `protected-commit` | A commit was blocked with "Protected state edit detected", or you are about to edit `AGENTS.md`, a lockfile, `.forge/config.yaml`, or a generated harness mirror. | `.forge/contributor-skills/protected-commit/SKILL.md` |
| `command-surface` | You are adding, renaming, or deleting a `lib/commands/*.js` file. | `.forge/contributor-skills/command-surface/SKILL.md` |
| `worktree-flow` | You are starting a piece of work, or two agents are about to touch the same repo at once. | `.forge/contributor-skills/worktree-flow/SKILL.md` |
| `agents-md-edit` | You want to change `AGENTS.md` — a workflow rule, a stage table, a maintainer note. | `.forge/contributor-skills/agents-md-edit/SKILL.md` |

## Provenance

Every rule in this tree carries an evidence tag:

- `[Forge #N ×n]` — mined from real corrections in this repo's session history
  (2026-08-13 transcript mining: 13 Claude sessions, 115 Codex sessions).
  `#N` is the rank in the mistake table, `×n` the observed frequency.
- `[verified 2026-08-13]` — read out of the running code on that date, with the
  file named.
- `[imported]` — a borrowed default with no local incident behind it. Imported
  rules are the first thing to cut at the next re-mine.

A rule with no tag has not earned its place. Delete it or find its evidence.
