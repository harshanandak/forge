# Forge

An open building-block platform for AI coding agents. Blocks declare their operations once; the CLI and MCP tools are generated from them; it works with any harness and any toolchain.

Status: rebuild in progress. The plan of record lives in the previous repository, [harshanandak/forge-legacy](https://github.com/harshanandak/forge-legacy) (`docs/work/2026-10-16-platform-rebuild/rebuild-plan.md`). npm package: `forge-workflow`; command: `forge`.
